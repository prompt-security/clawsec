# ClawSec README hero source

`hero-layout.svg` is the editable layout for the published `../hero.webp` asset. It composes two existing repository-native brand files instead of duplicating or regenerating them:

- `../../../public/img/mascot.png`
- `../../../img/Black+Color.png`

Keep the Prompt Security from SentinelOne lockup intact on its light plaque. The black wordmarks lose contrast when placed directly on the violet background.

Render the SVG in a standards-compliant browser at `1200 × 460`, then export the published WebP at the same dimensions. No generated artwork is used in this composition.
